# Oh My Arch v0.0.1

Release date: 2026-09-23

## Included

- x86_64 minimal profile
- Arch Linux `archiso`/`mkarchiso` backend
- GitHub Actions remote ISO build and checksum verification
- ISO, SHA256SUMS, and build manifest artifacts

## Support boundary

This release validates only `x86_64 + minimal + generic`. Other architecture,
profile, and platform combinations remain extension points rather than claimed
support.
