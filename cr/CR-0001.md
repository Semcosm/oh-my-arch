## Summary

Move ISO generation from the developer workstation to a reproducible GitHub Actions workflow backed by an Arch Linux container.

## Motivation

The repository should keep generated ISO files and build caches out of local working trees while retaining a predictable, auditable remote build path.

## Test Evidence

The `oma-build` workflow completed successfully on GitHub Actions run `35883327109`, including ISO generation, SHA256SUMS verification, and artifact upload. The `oma-check` workflow also passed on run `35883327150`. Local CLI, model, quality, supply-chain, action-pinning, and repository-shape checks passed before push.

## Risk

The workflow depends on the GitHub-hosted runner, Docker, and the current Arch Linux package repositories. Changes in runner images or upstream package availability may affect build duration or reproducibility.

## Rollback

Revert the CI migration commits and restore the prior local-build instructions and mirror configuration.

## Breaking Change

No CLI breaking change. Local builds remain available for development, but release-oriented ISO artifacts are now produced remotely.

## Backport Target

None.
