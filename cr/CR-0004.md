## Summary

Publish the repository's public SSH signer registry as the trust root for
signed commits and annotated release tags. Enforcement scripts and workflow
gates follow in the next signed push.

## Motivation

Make repository and release provenance auditable while keeping the encrypted
private signing key, passphrase, and SSH agent socket off-repository.

## Test Evidence

The bootstrap commit has an SSH signature from the registered key. The public
key and empty revocation file are present under keys/; no private material is
tracked.

## Risk

An incorrect signer registry can reject valid work or trust the wrong key.
Signer rotation must be reviewed as a security-sensitive change and completed
before dependent enforcement is enabled.

## Rollback

Revert the signer-registry commit and remove the registry files. No private key
material is created or removed by this change.

## Breaking Change

No existing build or CLI behavior changes. New signature enforcement is
introduced by a subsequent commit and does not retroactively require unsigned
history to be rewritten.

## Backport Target

None.
